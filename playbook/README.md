The playbook describes how teams publish, consume, and govern APIs through the API Marketplace.

## How the Marketplace works

1. **Producers** publish API contracts, documentation, and onboarding instructions through the Marketplace.
2. **Consumers** discover APIs in the catalogue, request access, and integrate using published contracts.
3. **Governance** is embedded in standards, tooling, and automation — not manual approval gates.

## Principles at a glance

The full principles are in [`product/principles.md`](../product/principles.md). The short version:

- API-first integration
- Make the right thing the easy thing
- Focus on organisational and partner boundaries
- Standards-based contracts and lifecycle
- Federated ownership — teams own their APIs
- Embedded governance, security, and observability
