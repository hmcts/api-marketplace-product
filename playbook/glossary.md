# Glossary

Key terms used across the API Marketplace.

| Term | Definition |
|------|------------|
| **API Product** | A managed, documented API offering with clear ownership, lifecycle controls, and published onboarding instructions. |
| **Consumer** | A team or service that integrates with an API product listed in the Marketplace. |
| **Producer** | A team that owns and publishes an API product through the Marketplace. |
| **Contract** | The machine-readable and human-readable API definition (e.g. OpenAPI spec). |
| **Catalogue** | The central registry of all API products available through the Marketplace. |
| **Recipe** | A reusable delivery pattern for a common API type, with documented trade-offs and a delivery checklist. |
| **Onboarding** | The process a consumer follows to gain access to and integrate with an API product. |
| **Lifecycle** | The stages an API product passes through: publication, versioning, deprecation, and decommissioning. |
| **Evidence** | Artifacts proving implementation and validation against a specification (e.g. test results, contract diffs, deployment records). |
| **Data-sharing agreement** | A formal agreement governing what data is exchanged across organisational or partner boundaries via an API. |
