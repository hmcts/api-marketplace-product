# AMp Recipes

Reusable API Marketplace design patterns.

"Recipe" is the team term for a repeatable implementation pattern with clear trade-offs. The same artifacts can also be referred to as design patterns in stakeholder conversations.

## Purpose

- Make proven AMp delivery patterns easy to reuse.
- Keep consistent non-functional expectations (security, reliability, observability).
- Reduce redesign effort across similar API initiatives.

## How to Use

1. Start with the [recipe template](recipe-template.md).
2. Keep recipes technology-agnostic where possible.
3. Link each API spec to one or more recipes when applicable.
